# Briefing

- Purpose: Fast Markdown viewer and editor built with Rust and Tauri (macOS + Windows).
- Scope: Multi-window viewer/editor for md/json/yaml/txt plus PDF viewing — GFM with syntect highlighting, KaTeX, Mermaid, callouts, collapsed front matter; on-type block-patched preview with bidirectional scroll sync; in-document anchors (Unicode heading slugs, footnotes), relative-link navigation, local images as data URIs; workspace folder with file tree, fuzzy switcher (Cmd+O), and full-text search tab (Cmd+Shift+F); CodeMirror 6 editor with vim mode, format shortcuts, multi-cursor, folding, inspector rail (counts + reading time + FK grade), clipboard image paste to assets/; docked find/replace, command palette (Cmd+K Cmd+P), session restore, native recents menu, HTML/PDF export with inlined images and custom preview CSS, three themes with HIG-native chrome, CLI launch.
- Key decisions: Rust owns rendering and sanitization (ammonia whitelist incl. class/id; ids md-prefixed in JS) behind a strict CSP with fully vendored frontend deps (KaTeX, Mermaid, CM6 bundle incl. codemirror-vim, pinned in scripts/vendor-codemirror.sh); all file IO gated by canonicalized path/dir grants with doc-dir containment for links/images (auto-grant under the doc's dir, escapes need an existing grant); prefs via tauri-plugin-store under pref_lock with a #[serde(default)] partial-map contract; startup launch intent enforced by the show-time gate (decision 126); version source of truth is package.json via scripts/sync-version.sh; releases are dev→main PR (main protected, "CI Success" required) then a lightweight tag on main triggering release.yml, with Casks/boltpage.rb pushed to Silverfell/homebrew-tap via update-cask.sh after each Release publishes; run cargo fmt and clippy -D warnings before any release.
- Areas: startup, editor, preview, workspace, prefs, menu, render, find, ui, release.
